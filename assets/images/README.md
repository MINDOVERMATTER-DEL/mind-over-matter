# Website images

Every image the website uses lives in this folder.

| Folder | What goes in it |
| --- | --- |
| `logo/` | The club logo (emblem, full logo, favicon, phone home-screen icon). `logo-original.jpg` is the source taken from the Articles of Association. |
| `team/` | Photos of committee members and founders. |
| `illustrations/` | Artwork and graphics, such as the home page illustration. |
| `community/` | Photos of club life (gatherings, sessions) used on the Home and About pages. Full-size originals are in `community/originals/`. |
| `merch/` | Product photos for the shop, cut from the design sheets. |
| `stats/` | Background photos for the home page statistics. `hospital-waiting-room.webp`: CCBRT Hospital, Tanzania, by Australia's Department of Foreign Affairs and Trade, CC BY 2.0 (credited on the page; <https://commons.wikimedia.org/w/index.php?curid=32167769>). |

Add new folders as needed (for example `events/` or `blog/`).

## Keeping images fast

- **Use WebP** where you can (most photo editors and <https://squoosh.app> export it). It is usually 3–5× smaller than PNG or JPG at the same quality. JPG is fine for photos; use PNG only for graphics that need sharp edges or transparency.
- **Don't upload huge photos.** Around 1600px wide is plenty for a full-width image; team photos only need about 320×320px.
- **Name files clearly** in lowercase with hyphens: `peer-support-circle-2026.webp`, not `IMG_4032 (1).JPG`.
- Images are compressed again automatically every time the site is built, so you don't need to do anything else.
- An image only appears on the site once it's referenced in the code, so ask for it to be added where you want it.
